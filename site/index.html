How it works

Three parts. Only your Mac holds the history.

~/code/api
$ am serve
  hooks   listening on 127.0.0.1:8787
  relay   connected, stores nothing
  found   4 agent sessions
$ am claude
⏺ The build is green. Migrating staging next.
? Run npm run migrate -- --env staging

stored 0

Your phonepaired device
  • Checks your device's token on every connection
  • Passes live updates between your Mac and your phone
  • Keeps no transcripts, no accounts and no history
am claude — ~/Projects/northstar
Do you want to proceed?
❯ 1. Yes  ← from your phone
⏺ Bash(npm run migrate)
  ✓ 3 migrations applied

No account. Nothing stored in the middle.

Pair with a code that works once. History stays on your Mac. Push alerts carry a session name, not your code. Live traffic passes through the relay, so you can run your own with one Docker command.

Get started

Install the command-line tool, pair your phone, start an agent.
$curl -fsSL https://agentman-nu.vercel.app/install | sh

Or with Homebrew: brew install lenajeremy/agentman/agentman. Either way you get tmux too, which Agentman uses to type into your agents.

$curl -fsSL https://agentman-nu.vercel.app/install | sh

For amd64 and arm64. Homebrew on Linux works too: brew install lenajeremy/agentman/agentman. Or build from a clone with Go 1.26.

Open the TestFlight invite

The app is in public beta on TestFlight. Open the invite on your iPhone and you'll get each new build as it ships.

Build the app from source with Expo. It runs and shows alerts while it's open; background push isn't set up on Android yet. Mobile setup guide

Then, on your computer
  1. am install-hooksconnect your agents, once
  2. am servestart Agentman, leave it running
  3. am pairscan the code with the app
  4. am claudestart an agent you can answer
