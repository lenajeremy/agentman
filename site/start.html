GET STARTED

Set up Agentman

Keep your existing agent tools. Connect Agentman on your computer, then pair your phone.

  1. Install
  2. Connect your agents
  3. Start Agentman
  4. Pair your phone
  5. Start an agent
  1. 1

    Install the command-line tool

    On your Mac or Linux machine, in a terminal. This puts am on your path.

    Install script · macOS and Linux
    $curl -fsSL https://agentman-nu.vercel.app/install | sh
    Or with Homebrew · macOS and Linux
    $brew install lenajeremy/agentman/agentman

    Agentman uses tmux to type into your agents. Homebrew brings it along; the install script tells you how to get it if you don't have it.

  2. 2

    Connect your agents

    Adds a small hook to Claude Code, Codex, Cursor and Antigravity, so each one tells Agentman the moment it finishes or stops to ask you something. Run it once.

    $am install-hooks

    To see the changes before they are made, run am install-hooks -dry-run. A Codex notify command you already have is left alone. Kiro's hooks are opt-in: am install-hooks -kiro.

  3. 3

    Start Agentman

    Finds the agents running on your machine and connects to the relay your phone talks to. Leave it running in a terminal tab of its own.

    $am serve
    hooks listening on 127.0.0.1:8787relay connectedfound 3 agent sessions
  4. 4

    Pair your phone

    Get the app first. Then, with am serve still running, open a second terminal:

    Get the iPhone app Android: build it with Expo
    $am pair

    In the app, tap Scan QR code and point it at your terminal, or tap Enter the code instead and type the ten digits. The code works once and expires after 60 seconds; run am pair again for a fresh one.

  5. 5

    Use your usual agent, through am

    Agents you start the usual way still show up on your phone, so you can follow them. Start them through am and you can also message them and answer their prompts.

    $am claude
    am codexam cursoram kiroam agyam opencodeam muse

    The agent's own command-line tool has to be installed and signed in already. Anything after the agent's name is passed to it, so am claude --resume works.

That's it.

When an agent finishes, or stops to ask you something, your phone tells you.

Something not showing up? am doctor checks that everything is wired up, and says what to fix.
